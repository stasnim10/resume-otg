# Resume Builder OTG Website

Marketing website for Resume Builder OTG, built with Next.js for easy deployment on Vercel's free tier.

## Run locally

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment variables

Optional:

```bash
NEXT_PUBLIC_APP_URL=https://your-streamlit-app-url
NEXT_PUBLIC_SUPPORT_EMAIL=you@example.com
NEXT_PUBLIC_LINKEDIN_URL=https://www.linkedin.com/in/your-profile/
```

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the repo into Vercel
3. Set the project root to `website`
4. Add any optional environment variables
5. Deploy
