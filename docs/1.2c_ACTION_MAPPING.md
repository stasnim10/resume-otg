# Task 1.2c: Action Mapping

## Score Bands

- `75+`
  Primary action: `Apply Now`
  Supporting message: `This is a strong match.`

- `60-74`
  Primary action: `Review Enhancement`
  Supporting message: `One improvement would boost your chances.`

- `<60`
  Primary action: `Skip This Role`
  Supporting message: `Major gaps are still visible.`

## Notes

- `Apply Now` routes users forward to run mode.
- `Review Enhancement` keeps users on the report and opens details.
- `Skip This Role` routes users back to input so they can try another job.
