# Metrics Baseline

## Student Persona (College Job Seeker)
- Metric 1: Time from landing to first "Optimize" click
  Current baseline: Not yet instrumented; estimate by observing 1-2 student users and adding logging around upload, import review, and optimize actions
  Target: 3 minutes

- Metric 2: Anxiety level immediately after file upload (1-10 scale)
  Current baseline: Not yet measured; ask 1 student user to rate confidence/anxiety after upload confirmation appears
  Target: Less than 5/10

- Metric 3: Confidence score after seeing resume changes (1-10 scale)
  Current baseline: Not yet measured; collect after before/after review with 1 student user
  Target: 7+/10

## Professional Persona (Mid-Career Switcher)
- Metric 1: Time to understand the recommended next action after receiving a fit report
  Current baseline: Not yet measured; observe whether a professional user can explain the next step without prompting
  Target: Less than 45 seconds

- Metric 2: Trust in output quality after optimization review (1-10 scale)
  Current baseline: Not yet measured; ask 1 professional user whether the changes feel materially better than a generic AI rewrite
  Target: 8+/10

- Metric 3: Percentage of sessions where the user completes optimization without reopening the original resume for reassurance before acting
  Current baseline: Not yet measured; track via observation during moderated testing
  Target: 70%+

## Executive Persona
- Metric 1: Time to determine whether the app is credible enough to continue using
  Current baseline: Not yet measured; observe first impression and ask for go/no-go decision during first session
  Target: Less than 60 seconds

- Metric 2: Embarrassment risk score after reviewing rewritten content (1-10 scale, lower is better)
  Current baseline: Not yet measured; ask 1 executive user whether any language feels inflated, generic, or reputation-damaging
  Target: Less than 3/10

- Metric 3: Approval confidence for using the optimized resume in a real application (1-10 scale)
  Current baseline: Not yet measured; collect immediately after side-by-side review of original vs optimized version
  Target: 8+/10
