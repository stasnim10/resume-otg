# Task 1.1a: Profile Import Architecture

## Current State

- The profile review flow lives in [`resume_optimizer_local/streamlit_app.py`](/Users/simumtasnim/App Wizard/Resume Builder OTG/resume_optimizer_local/streamlit_app.py:1812).
- The screen already expands only the first 3 extracted items by default, but it still renders every extracted item in the same review pass.
- Users immediately see the full profile basics form plus a long list of extracted items, which creates cognitive overload even when later items are collapsed.
- The current section title emphasizes quantity: "`N` suggested items are ready to save," but it does not stage the work as "review a few now, reveal the rest only if needed."

## Problem to Solve

- Users are being asked to process identity fields, summary fields, targeting fields, and a potentially large extracted-item list all on one screen.
- Even with collapsed expanders, the visible item stack signals "there is a lot to manage," which increases anxiety and slows the next decision.
- The screen should answer one question first:
  "Which items do I want to keep from this import?"

## Decisions Made

### Sort Order
Decision: Sort by category, with `experience` and `project` items first, then leadership/education, then everything else. Within each category, sort by confidence score descending.

Rationale:
- Users are most likely to recognize work experience and projects fastest, so these items create the strongest early sense of trust.
- Confidence-only sorting may surface less important items before core work history.
- Category-first ordering better supports the student and professional personas, who want immediate proof the app understood the strongest evidence correctly.

### Reveal Pattern
Decision: Use a button labeled `View X More`.

Rationale:
- A button makes the hidden scope explicit without implying users must inspect everything.
- The exact count reduces uncertainty and reassures users nothing is lost.
- This is a clearer, lower-friction pattern than pagination for a one-time review step.

## Proposed Interaction

1. User lands on the review screen after profile extraction.
2. The screen confirms success and explains that only 3 items are shown first.
3. The first 3 items appear in priority order.
4. A `View X More` button reveals the remaining extracted items below the primary review set.
5. The save action remains available after users confirm or edit the visible items.
